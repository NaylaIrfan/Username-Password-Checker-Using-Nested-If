# Username-Password-Checker-Using-Nested-If
A simple C++ program that checks whether the entered username and password are correct. This project demonstrates the use of nested if statements for basic login authentication.

The program is designed for beginners to understand how nested if statements work in C++.

Features

Takes username as input
Checks whether the username is correct
Takes password only when the username is correct
Checks whether the password is correct
Displays a login success or error message

Concepts Used

C++
if-else statements
Nested if
String variables
user input using cin
Output using cout

How It Works

The user enters a username.
The program checks the username.
If the username is correct, the program asks for the password.
The password is checked using a nested if statement.
If both are correct, Login Successful is displayed.

Example

Enter username: NAYLA
Enter password: 12345
Login Successful!

Requirements

Any C++ compiler
C++11 or later
